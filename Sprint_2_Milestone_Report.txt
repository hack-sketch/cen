# 1. Sprint 2 Overview

Sprint 2 (Milestone 4) represents the complete production-grade completion and full-stack integration of the Community Exchange Network (CEN) — a hyper-local, credit-backed skill and resource sharing platform engineered for residential building societies, gated apartments, and housing complexes. Spanning the execution period from 3 August 2026 to 12 August 2026 (Week 8–9), the engineering team expanded, hardened, and verified an asynchronous RESTful API architecture using FastAPI (Python 3.10), SQLAlchemy 2.0 ORM, SQLite (cen.db), Google Gemini LLM, and a modern TanStack React 19 / Vite 8 frontend.

The core objective of Sprint 2 was the production-grade completion of the hyper-local, credit-backed skill and resource sharing platform for residential societies — resolving administrative friction, enforcing marketplace lending lifecycles, delivering granular coordinator governance and multi-resident household approvals, with context-aware AI across every community workflow. The backend implements 88 RESTful API operations partitioned across 14 modular routers, supported by a 38-case pytest test suite (100% pass rate) and an interactive Playwright E2E browser automation test suite (run_full_e2e_browser_test.py). All endpoints are fully documented in an updated OpenAPI 3.0.3 specification (swagger.yaml) and served live via interactive Swagger UI (/docs) and ReDoc (/redoc) interfaces.

# 5. Pytest Implementation

All test cases are implemented using pytest with a shared conftest.py fixture that creates an isolated, in-memory SQLite database (sqlite:///:memory:) for fast and reproducible testing.

### Test Setup — conftest.py

The shared test configuration (backend/tests/conftest.py) defines:
1. In-Memory SQLite Database Engine: Uses sqlite:///:memory: with SQLAlchemy's StaticPool for thread-safe, fast execution in memory without polluting disk data (cen.db).
2. Function-Scoped Database Fixture (db_session): Builds all tables before each test and drops all tables cleanly on teardown.
3. FastAPI TestClient Fixture (client): Overrides FastAPI's get_db dependency using app.dependency_overrides[get_db].

### Instructions to Run the Application

#### Backend Setup (Windows / macOS / Linux)

1. Clone the repository and navigate to the backend directory:
   git clone <repository-url>
   cd MAY2026-Team-094/backend

2. Create and activate a Python virtual environment:
   # Windows:
   python -m venv venv
   venv\Scripts\activate

   # macOS / Linux:
   python3 -m venv venv
   source venv/bin/activate

3. Install required backend dependencies:
   pip install -r pyproject.toml

4. Create environmental configuration file .env:
   cp .env.example .env
   # Ensure GEMINI_API_KEY and SECRET_KEY are configured

5. Run the FastAPI development backend server:
   python -m uvicorn src.main:app --host 127.0.0.1 --port 8000 --reload
   The backend API will start at http://localhost:8000.

---

#### Frontend Setup

1. Open a new terminal and navigate to the frontend directory:
   cd MAY2026-Team-094/frontend

2. Install Node.js dependencies:
   npm install

3. Start the Vite development server:
   npm run dev -- --port 8080
   The web application will open at http://localhost:8080.

---

#### Running Tests

To run the automated Pytest backend suite:
cd MAY2026-Team-094/backend
python run_tests.py

To run the Playwright browser E2E test suite:
cd MAY2026-Team-094
python run_full_e2e_browser_test.py
