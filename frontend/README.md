# CEN — Community Exchange Network (Frontend)

### 1. Installation
Run the following command to install dependencies:

```bash
npm install
```

### 2. Run the Development Server
Launch the development server:

Using npm:
```bash
npm run dev
```

Access the application in your browser at `http://localhost:3000` (or the port specified in your terminal).

### 3. Build for Production
To bundle and optimize the application for production:

Using npm:
```bash
npm run build
```
